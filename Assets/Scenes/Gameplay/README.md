# Gameplay Hierarchy

## Controllers

- DeploymentController
Handles the deployment phase of the gameplay => handles logic for selecting waypoint markers, then instantiation and animation of ships into the scene.

- GameController
Handles main game logic (need to be AI, movement etc)

- PlayerShipController
Ship selector (number)
Creation of the player ships

- ShipData
Handles object creation and stat instantiation of the ship's data
